# Quickstart ⚡

This path gets you from **clone → running app** in under 90 seconds.

## Prerequisites

- **Node.js**: 20+
- **pnpm**: 10+ (Recommended)

## 1) Clone & Enter

```bash
git clone https://github.com/acidgreenservers/MindSeeds.git
cd MindSeeds
```

## 2) Install & Launch

```bash
pnpm install
pnpm dev
```

## 3) Access the Registry

Open your browser to:

- **App**: [http://localhost:5173](http://localhost:5173)

## 4) Verify Build

Ensure the project is production-ready:

```bash
pnpm build
pnpm preview
```
